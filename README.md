# OBSERVED WORLD / 観測される街

**猫の視点を介して、観察者ごとに異なる合成世界で住民と猫の行動を観測する研究向けWebシミュレーションのプロトタイプです。ゲームではありません。**

## 実装済み
- 初回アクセスでブラウザごとに観察者シードを生成。街区配置、緑地、建物、住民配置、猫、天候がシードに依存
- 24人の合成人間、9匹の猫。空腹・エネルギー・社交・ストレス・気分の状態を保持
- 時刻、性格傾向、天候、職業、欲求に基づく有限状態の行動選択と経路探索
- 個体間の近接条件・確率・クールダウンを用いた人間の交流、人間と猫の接近
- 猫の切替操作。選択解除された猫は自律行動へ復帰。WASD/矢印またはタッチ十字キーで操作
- 2Dの観察フィールド、自由なカメラ、ズーム、個体検査パネル、行動ログ、指標
- 観察状態を Cookie に分割して自動保存。JSON入出力、観測ログCSV出力
- 任意の Gemini API キーをサーバ側に設定すると、生成AIで個体ごとの初期性格を作成。**未設定の場合は規則ベース**に切替

## ローカルで起動
Node.js 20以上。ライブラリ依存なし。

```bash
npm start
# http://localhost:3000
npm test
```

## Render（Web Service）
1. このフォルダの内容を GitHub リポジトリに push。
2. Render > New > Web Service でリポジトリを選択。
3. Runtime `Node` / Build Command `npm install --no-audit --no-fund` / Start Command `npm start` / Freeプラン（選択可能な場合）。
4. 任意：Environment に `GEMINI_API_KEY` を秘密値として追加。モデル指定は `GEMINI_MODEL` （初期値 `gemini-2.5-flash`）。**キーをGitHubに公開しないでください。**
5. 自動デプロイを有効にする。

## 保存について
Cookieは1件およそ4 KBの上限があり、世界の記録を多数のCookieへ分割しています。ブラウザのCookie消去、プライベートブラウズ、利用者側の保存制限等で消える場合があります。長期の研究データは定期的に **JSON出力** で保存してください。HTTP通信によってCookieがサーバへ送信されるのを抑える目的で、API/静的ファイルへのリクエストが発生し得ることにも注意が必要です。このプロトタイプにはログイン・サーバ側の状態共有はありません。

## 限界と研究用途上の注意
- **現実の人間の行動を科学的に再現・予測するモデルではありません**。現実の動機・社会構造・コミュニケーションは高度に単純化されています。
- 「AI」は初期の**架空人物の性格付け**にのみ使用可能。毎フレームの行動は透明性・決定可能性のためルールベース。APIキーがない限りAIモデルは使用されません。
- 観察者が操作する猫は世界へ介入するため、非介入の観察とは区別し、`observer` イベントと介入距離を記録します。
- Cookieに保存できる量には限界があり、長大な履歴は全保存できません。多日・多個体の分析にはDBやファイル出力の拡張が必要。
- 長時間放置してブラウザタブを閉じているあいだのシミュレーション進行はありません。開き直すと保存時点から再開します。
- 共有URLで異なる観察者が別世界を見る方式で、複数人が同じ世界を観察するオンライン同期は行いません。
